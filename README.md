## 주요 디렉터리 생성
components : 리덕스 상태에 연결되지 않은 프리젠테이셔널 컴포넌트위치, 각 컴포넌트의 스타일도 이 디렉터리에 위치 \
pages : 라우터에서 사용할 각 페이지 컴포넌트 위치 \
store : Ducks 구조를 적용시킨 리덕스 모듈들과 스토어 생성 함수 위치 \
styles : 폰트, 색상, 반응형 디자인 도구, 그림자 생성 함수 등 프로젝트에서 전역적으로 필요한 스타일 관련 코드 위치 \
api : 서버 연동하여 데이터 핸들링 \


## pages 구조

#### campaign : 광고관리 , 캠페인 생서, 크리에이티브 관리
#### signup : 회워가입 , 약관등록 
#### login : 로그인 , 아이디찾기, 비밀번호 찾기
#### main : 메인페이지 ,최초 진입 페이지
#### dash_board :로그인시 첫 페이지 챠트와 광고 리스트 
#### platform_manage : 플랫폼 관리 - 사용자관리 ,광고주 카테고리 관리, 상품수집관리, 전환관리, 결제관리, 광고비 지급관리 
#### layout : 메뉴 구성
#### pixel : 픽셀 관리
#### settings: 이벤트 단가 관리, 이벤트 예산 관리, 시간대별 예산 관리
#### reports : 보고서 생성, 커스텀 보고서
